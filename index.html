A Evolução do HTML

Uma linha do tempo da principal linguagem de marcação da Web

1991 - HTML 1.0

Criado pelo físico Tim Berners-Lee no laboratório CERN, na Suíça, o HTML nasceu com um propósito simples: permitir o compartilhamento de documentos científicos através de hipertextos (links). Essa versão era extremamente rudimentar, suportando apenas textos e links, sem nenhuma capacidade de formatação visual, imagens ou tabelas.

1995 - HTML 2.0

Com o rápido crescimento da internet, surgiu a necessidade de organizar a linguagem. O HTML 2.0 foi a primeira versão a se tornar um padrão oficial pela IETF (Internet Engineering Task Force). A grande novidade foi a introdução de recursos de interação básica, como a criação de formulários (tags

e ), permitindo que os usuários enviassem dados aos sites pela primeira vez.

1997 - HTML 3.2

O recém-criado W3C (World Wide Web Consortium) assume o controle da padronização do HTML. A versão 3.2 trouxe avanços visuais importantes, permitindo o uso de tabelas complexas, alinhamento de texto, cores de fundo e a capacidade de fazer o texto fluir ao redor das imagens. Também foi adicionado o suporte para pequenos programas em Java (Applets).

1999 - HTML 4.01

Um dos marcos mais importantes da história da web. O HTML 4.01 começou a "limpar" o código, desestimulando o uso de tags apenas visuais (como "a tag "fonte" e a "center"). O objetivo era separar a estrutura (o que fica no HTML) do estilo e design (que passaria a ser responsabilidade exclusiva do CSS)

2000 - XHTML 1.0

O W3C decidiu reescrever o HTML usando as regras do XML, criando o XHTML. O foco era a padronização extrema para que a web funcionasse em diferentes dispositivos, como os primeiros celulares. A sintaxe tornou-se muito rigorosa: todas as tags precisavam ser escritas em letras minúsculas, aninhadas perfeitamente e obrigatoriamente fechadas.
